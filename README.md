# ImageLite API 📸

Este é um projeto desenvolvido para consolidar e retomar conhecimentos fundamentais em desenvolvimento **Backend** utilizando o ecossistema **Java** e o framework **Spring Boot**.

## 🚀 Objetivo
O foco principal deste repositório é praticar a construção de APIs robustas, explorando as funcionalidades do Spring e as melhores práticas de desenvolvimento, como organização de camadas, injeção de dependências e persistência de dados.

## 🛠️ Tecnologias Utilizadas
* **Java 17** (ou a versão que você estiver utilizando)
* **Spring Boot 3**
* **Spring Data JPA**
* **Maven** (Gerenciador de dependências)

## 📋 Funcionalidades em Estudo
- [x] Configuração inicial do projeto com Spring Initializr.
- [ ] Criação de endpoints REST.
- [ ] Integração com banco de dados.
- [ ] Manipulação e armazenamento de imagens (funcionalidade core da API).
